# CodeAlpha Python Internship

## Project 1: Basic Chatbot

### Description
This is a simple rule-based chatbot developed using Python.

The chatbot can:
- Greet the user
- Answer basic questions
- Introduce itself
- Respond to predefined commands
- Exit when the user types "bye"

### Technologies Used
- Python 3

### How to Run

Open terminal and execute:

```bash
python chatbot.py
```
